## Featured Project

### [Sales Data Analytics & Business Intelligence Dashboard for PT Sejahtera Bersama](https://github.com/fadilirsyadm/sales-data-analytics-dashboard)

A Business Intelligence project completed as the final task of the **Business Intelligence Analyst Project-Based Internship at Bank Muamalat x Rakamin Academy**.

The project covers:

- Identifying primary keys and relationships across customer, order, product, and product-category datasets
- Building an integrated master table using Google BigQuery
- Exporting the processed dataset into CSV format
- Developing an interactive sales dashboard using Google Looker Studio
- Analyzing sales, order quantity, customer, product-category, and city-level performance
- Preparing business recommendations to maintain and improve sales performance

**Dashboard highlights**

| Metric | Result |
|---|---:|
| Total Sales | $1,754,750.57 |
| Total Orders | 3,339 |
| Units Sold | 11,654 |
| Unique Customers | 1,671 |
| Average Order Value | $525.53 |
| YoY Sales Growth | -7.85% |
